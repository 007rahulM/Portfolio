This portfolio is a product, not a résumé. Every section is built to answer a recruiter’s silent questions: **What does Rahul build? How does he think? Can he ship?**

## Why Next.js 14
- App Router keeps routing predictable.
- Server Components let me push data work to the server.
- SEO is handled by default with metadata.

## The shift in mindset
Backend work is about **systems** and **edge cases**. UI work is about **clarity** and **intent**. I’m learning to treat spacing and typography the way I treat API design: with structure and reason.

## What I’m practicing
- TypeScript for safer refactors
- Component boundaries (server vs client)
- Tailwind for rapid, consistent styling
