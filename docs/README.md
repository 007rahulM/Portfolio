# 📚 Portfolio Docs Hub

Welcome. This docs folder is the teaching branch for the portfolio project. It is written so a new developer can **read, understand, and rebuild this portfolio end‑to‑end** — while also learning the why behind each decision.

## How to Use This Docs Hub

Start with **Learning** to understand the stack and fundamentals. Then go to **Build** to follow the actual project walkthrough. Use **Setup** anytime you need to configure tools or run the project locally.

```
docs/
├── README.md                 ← You are here. Start here.
├── setup/                    ← Local/dev/deploy setup guides
├── learning/                 ← Concept-by-concept teaching
└── build/                    ← Step-by-step project walkthrough
```

## Where to Start

- **New to the stack?** → `learning/README.md`
- **Need to run the project?** → `setup/README.md`
- **Want to build it step‑by‑step?** → `build/README.md`

## What This Repo Teaches

- Next.js 14 (App Router) fundamentals
- TypeScript + React component design
- Contentlayer + MDX content pipelines
- Tailwind CSS design system
- Framer Motion animation patterns
- Real project structure and decision‑making

The goal is not just to copy code — it’s to **understand every piece**, so you can rebuild and extend it on your own.
