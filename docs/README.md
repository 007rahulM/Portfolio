# 📚 Portfolio Docs Hub

Welcome to the teaching version of this portfolio. The goal of this docs folder is **not** to give you shortcuts — it is to help you **understand every decision, every file, and every line of behavior** so you can build the project yourself and make your own changes with confidence.

If you have basic web knowledge but can’t yet write a full project from scratch, this documentation is written for you.

## How to Use This Docs Hub

Think of the docs as a three‑stage learning path:

1. **Learning** — build your mental model of the stack.
2. **Setup** — make sure your environment and tooling work.
3. **Build** — walk through the actual code step by step and understand what it does.

```
docs/
├── README.md                 ← You are here. Start here.
├── setup/                    ← Local/dev/deploy setup guides
├── learning/                 ← Concept-by-concept teaching
└── build/                    ← Step-by-step project walkthrough
```

## Where to Start

- **New to the stack?** → `learning/README.md`
- **Need to run the project?** → `setup/README.md`
- **Want to rebuild it?** → `build/README.md`

## How to Learn From This Repo (Important)

When you read a doc page, don’t just skim. Practice this routine:

1. **Read the goal** (what problem that page solves).
2. **Study the mental model** (how you should think about it).
3. **Open the referenced files** and read them line by line.
4. **Explain each part out loud**: what it does, what data it uses, and why it exists.
5. **Make a tiny change** and confirm you understand the effect.

If you can explain the reason behind a file, you can rebuild it.
