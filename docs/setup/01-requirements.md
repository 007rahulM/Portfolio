# 01 — Requirements

This project is a **Next.js 14** app with TypeScript, Tailwind CSS, and Contentlayer. You only need a modern Node.js environment.

## Required tools

- **Node.js** (LTS recommended)
- **npm** (comes with Node)

## Recommended tools

- **VS Code** (or any TypeScript‑friendly editor)
- **Git** for version control

## Verify your environment

```bash
node -v
npm -v
```

If those commands work, you’re ready for local development.
