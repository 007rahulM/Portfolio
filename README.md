# Rahul M Portfolio

A Next.js 14 + TypeScript + Tailwind portfolio focused on backend craftsmanship, AI-integrated projects, and frontend growth.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- MDX + Contentlayer

## Commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Content updates

- Add projects in `content/projects/*.mdx`
- Add blog posts in `content/blog/*.mdx`
- Learning docs live in `docs/`
